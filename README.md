# 🛒 Supermarket Catalog Website

پلتفرمی برای نمایش تخفیف‌ها و محصولات سوپرمارکت‌های مختلف

## ✨ ویژگی‌های اصلی

### مرحلة 1: آپلود تخفیف‌ها
- دریافت تخفیف‌های فیسبوک سوپرمارکت‌ها (متن + عکس)
- آپلود خودکار روی سایت
- نمایش متن تخفیف و عکس محصولات با قیمت

### مرحلة 2: پنل مدیریت
- ایجاد حساب کاربری برای هر سوپرمارکت
- اضافه کردن تخفیف‌ها بصورت خودکار
- مدیریت اشتراک ماهیانه (پرداخت/تمدید)
- بررسی و تایید تخفیف‌ها

### مرحلة 3: صفحة اصلی
- **اسلایدر تبلیغات** برای نمایش تخفیف‌های فعال
- دسته‌بندی سوپرمارکت‌ها
- فیلتر بر حسب نوع محصول
- جستجو میان تخفیف‌ها

## 🛠️ تکنولوژی‌های استفاده شده

**Frontend:**
- HTML5, CSS3, JavaScript
- Bootstrap/Tailwind CSS (برای طراحی)
- Swiper.js (برای اسلایدر)

**Backend:**
- Node.js + Express
- MongoDB (ذخیره داده‌ها)
- JWT (احراز هویت)

**Admin Panel:**
- Dashboard برای مدیریت
- صفحة پرداخت اشتراک
